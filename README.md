# tw-property-sheet｜物調表自動產生器

房仲接到委託後，要填一張「物件調查表」：地址、地段、坪數、樓層、屋齡、結構、車位、周邊機能……
很多資料其實**謄本裡有、公開地圖查得到**，卻還是要一格一格手打。這個工具會：

- **輸入地址 → 自動查**：座標、縣市鄉鎮、村里、地段，以及最近的公園、車站、超市（公開服務，免金鑰）
- **上傳土地／建物謄本 PDF → 自動填**（可一次選多份，電傳版和地政事務所正本都看得懂）：
  - 建物：建號、坐落地號、主建物／附屬建物／公設坪數、各層面積、層數、層次、完工日期、屋齡、結構、權利範圍
  - 土地：地段地號、面積、使用分區／使用地類別（自動判斷都計內外）、公告土地現值、公告地價、權利範圍與持分坪數
- **上架前風險提示**（🔴🟡🟢）：1 年內取得（房地合一短期交易）、抵押等他項權利、謄本超過 30 天、委託書坪數和謄本差超過 3%、持分要共有人同意
- **地號 → 地籍圖**：在國土測繪底圖上畫出地號形狀（一筆地號由好幾塊組成也畫得出來），附約略面積、面寬與深度
- （選用）**官方土地面積核對**：自備內政部地政平台金鑰，一鍵查土地登記標示部的官方面積並和表單比對；要確認才查、同一筆只收一次費、有每日上限。**尚未接真實平台實測**（目前只用模擬回應測試），原則上請先拿一筆已知正確的地號比對確認後再使用
- 自動算**權狀合計坪數、單價（萬／坪）、屋齡、公告現值換算每坪**
- 一鍵產生 **A4 一頁的物調表 Excel**，**必填但沒填的欄位會標黃**；可附**現場照片**（放第二頁，自動縮圖、去除 GPS 等 EXIF）
- （選用）接 Claude API 產生**案名**和**銷售重點**；不接也能用，會用簡單規則代替

> 範本是本專案自己設計的通用格式，不屬於任何品牌。自動查詢的資料來自公開服務，原則上僅供參考，物件資訊請以登記謄本、主管機關資料與現場確認為準。

## 需要哪些金鑰？

**不用任何金鑰就能用全部主要功能**（地址查詢、謄本解析、風險提示、地籍圖、產生 Excel）。下面兩項是選用的加值功能，會產生費用：

| 功能 | 要申請什麼 | 費用 |
|---|---|---|
| AI 產生案名、銷售重點 | Anthropic（Claude）API 金鑰 | 依用量計費，每次通常不到新臺幣 1 元 |
| 🏛️ 官方土地面積核對 | 內政部「地政整合資訊服務共享協作平台」Client ID＋安全碼 | 每筆收費（目前約新臺幣 1 元，以平台公告為準） |

👉 **申請步驟、填寫位置、省錢防呆設計與安全注意事項，請看 [docs/金鑰申請.md](docs/金鑰申請.md)**。
有填金鑰時請不要把網頁直接公開到網路上，否則別人按按鈕的費用會算在你的金鑰上。

## 怎麼用

**需要：** Python 3.10 以上（[python.org](https://www.python.org/downloads/)，Windows 安裝時勾選「Add python.exe to PATH」）。

1. 下載這個專案（綠色 **Code** 按鈕 → **Download ZIP**），解壓縮，在資料夾裡執行：

   ```bash
   pip install -r requirements.txt
   ```

2. （選用）把 `.env.example` 複製成 `.env`，改 `PSHEET_BRAND`（顯示在頁面和 Excel 上的店名）。
3. 啟動：
   - **Windows**：雙擊 **`背景啟動.vbs`**（背景執行，不跳黑色視窗；紀錄在 `data\psheet.log`）。停止用 **`停止.vbs`**。
   - **macOS／Linux**：`python3 main.py`
4. 打開 http://localhost:8000 ，照五個步驟填：
   1. **基本資料**：物件編號、地址 → 按「自動查詢」
   2. **物件資訊**：上傳建物謄本 PDF → 按「解析謄本」；選土地分區、外觀結構
   3. **坪數樓層**：檢查自動帶入的坪數、樓層、完工日
   4. **周邊資料**：學區、周邊機能、車位、管理費
   5. **確認下載**：產生案名、銷售重點 → **下載 Excel**

### 謄本與個資

- 謄本請用你**合法申請**的電子謄本。解析只在你自己的電腦上進行，不會上傳到別的地方。
- 解析**只抓物件資料與風險判斷需要的資訊**（權利範圍、取得日與原因、他項權利種類與擔保金額），**不抓所有權人、他項權利人等姓名與統一編號**。
- 掃描成圖片、沒有文字層的謄本抓不到資料，請手動填。
- 有開 AI 功能時，送給 Claude 的只有物件條件（地址、坪數、格局、周邊），不含謄本原文。

### 多人使用與對外架設（請先看）

- **本工具沒有登入機制。** 預設只開在 `127.0.0.1`（只有本機能連）。把 `PSHEET_HOST` 改成 `0.0.0.0`、架到雲端、或用 cloudflared／ngrok 對外開放，**任何拿到網址的人都能上傳檔案、使用你的 AI 與地政平台額度**。
- 要給同事一起用：只在公司內網使用，或在前面加登入保護（Cloudflare Access、Nginx／Caddy 帳號密碼）。啟動時若偵測到對外監聽會在紀錄裡警告。
- 上傳的謄本 PDF、照片只在記憶體處理，**不寫入硬碟**；每份 Excel 都是各自產生、直接回傳給送出請求的人，不會留檔，也沒有可猜的下載網址。
- 請用**單一程序**執行（`python main.py`），不要用 `uvicorn --workers N`：地政平台的「每日上限」與「同一筆只收一次」是靠程序內的鎖，多程序無法保證。
- 地政平台每日上限以**台灣時間**換日。用量檔 `data/moi_usage.json` 若損毀，程式會**拒絕查詢**（避免用量歸零後重複扣款），請檢查或刪除該檔。
- 解析 PDF 有大小（15MB）、頁數（40 頁）與時間（`PSHEET_PDF_TIMEOUT`，預設 40 秒）限制。
- 寫進 Excel 的文字若以 `=`、`+`、`-`、`@` 開頭，一律當純文字，不會被 Excel 當公式執行。

### 自己改範本或選單

- **下拉選單**：改 `options.json`（例如把你們店的營業員、常用車站、市場加進去）。
- **版面**：改 `sheet/layout.py` 的 `LAYOUT`，範本和填寫位置會一起變，不會對不上。
- 想用自己畫好的 Excel：版面要和 `LAYOUT` 一致，在 `.env` 設 `PSHEET_TEMPLATE=你的檔案.xlsx`。

### 選用：AI 產生案名與銷售重點

在 `.env` 填 `ANTHROPIC_API_KEY`（到 [Claude Console](https://console.anthropic.com/) 申請），重新啟動即可。
AI 被要求只根據你填的資料寫，不寫保證增值等誇大字眼；產生後仍請自己看過再用。會花 API 費用。

## 資料來源

| 用途 | 服務 | 備註 |
|---|---|---|
| 地址轉座標 | [ArcGIS World Geocoding](https://developers.arcgis.com/rest/geocode/) | 不儲存結果的單筆查詢免金鑰 |
| 門牌定位（優先） | 國土測繪中心門牌查詢 | 只接受門牌完全相符，查不到才改用 ArcGIS |
| 縣市、鄉鎮、村里、地段 | [內政部國土測繪中心開放 API](https://api.nlsc.gov.tw/) | |
| 地段代碼、地號形狀 | [國土測繪圖資服務雲](https://maps.nlsc.gov.tw/) | 面積是圖面估算的約略值，正式以謄本為準；一次查一筆，程式每 0.5 秒最多 1 次請求，請勿批次大量查詢 |
| 官方土地面積（選用） | [地政整合資訊服務共享協作平台](https://cop.land.moi.gov.tw/) | 自備金鑰、按筆收費，**尚未接真實平台實測**；面積欄位名稱可用 `PSHEET_MOI_AREA_FIELD` 指定，見 [docs/金鑰申請.md](docs/金鑰申請.md) |
| 公園、車站、超市 | [OpenStreetMap](https://www.openstreetmap.org/copyright) Overpass API | © OpenStreetMap contributors；公開站台常限流，程式會依序換站 |

公開服務可能改版、限流或暫停，查不到的欄位會留空，照樣可以手動填。
Python 3.13 以後對憑證檢查變嚴格，部分政府網站的憑證會被誤擋；本程式**仍然驗證憑證**，只關掉那項嚴格檢查。

## 給開發者

| 檔案 | 用途 |
|---|---|
| `main.py` | FastAPI：頁面與 API |
| `sheet/layout.py` | 版面定義、欄位換算（合計坪數、單價、屋齡、組合字串） |
| `sheet/excel.py` | 用 openpyxl 畫範本、填資料、標黃 |
| `services/geo.py` | 定位、行政區、周邊設施 |
| `services/tenement.py` | 土地／建物謄本 PDF 文字解析（兩種格式） |
| `services/risk.py` | 上架前風險提示 |
| `services/parcel.py` | 地段代碼、地號形狀與約略面積、國土測繪門牌定位 |
| `services/moi.py` | 選用：內政部地政平台官方土地標示部（自備金鑰、快取、每日上限） |
| `services/ai.py` | 選用的 Claude 案名／銷售重點 |
| `static/` | 前端（五步驟表單） |

測試（不連網）：

```bash
python -m unittest discover -s tests
```
