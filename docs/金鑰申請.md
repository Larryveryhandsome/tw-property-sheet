# 金鑰申請與設定教學（tw-property-sheet）

> **先講結論：不申請任何金鑰也能用。** 地址查詢、謄本解析、風險提示、地籍圖、產生 Excel 都免金鑰。
> 下面兩種金鑰都是**選用**的加值功能，而且**都會產生費用**，請看完費用與安全說明再決定要不要開。

| 功能 | 要申請什麼 | 費用 | 填在 `.env` 的欄位 |
|---|---|---|---|
| AI 產生案名、銷售重點 | Anthropic（Claude）API 金鑰 | 依用量計費，產生一次案名＋銷售重點通常不到新臺幣 1 元 | `ANTHROPIC_API_KEY` |
| 官方土地面積核對 | 內政部「地政整合資訊服務共享協作平台」Client ID＋安全碼 | 每查一筆收費（目前約新臺幣 1 元，以平台公告為準） | `MOI_COP_CLIENT_ID`、`MOI_COP_SECRET` |

---

## 先做一次：建立 `.env` 檔

1. 在專案資料夾找到 **`.env.example`**，複製一份，檔名改成 **`.env`**（Windows 若看不到副檔名：檔案總管 →「檢視」→ 勾選「副檔名」）。
2. 用記事本打開 `.env`，把下面申請到的值填在等號後面，**不要加引號、不要有空格**。
3. 存檔後重新啟動程式（雙擊 `停止.vbs` 再雙擊 `背景啟動.vbs`，或重開 `python main.py`）。
4. 打開 http://localhost:8000/health ，`"ai": true` 表示 AI 金鑰讀到了；頁面上「官方面積核對」按鈕滑鼠移上去會顯示今天已查幾筆。

> 🔒 `.env` 已列在 `.gitignore`，不會被 git 上傳。**不要把 `.env` 傳到 LINE、Email、雲端硬碟，也不要截圖給別人。**

## 一、Anthropic（Claude）API 金鑰 — AI 案名與銷售重點

### 申請步驟

1. 打開 [Claude Console](https://console.anthropic.com/)，用 Email 或 Google 帳號註冊並登入。
2. 第一次使用會請你建立組織（Organization），名稱填公司或自己的名字即可。
3. **先儲值**：左側「Settings」→「Billing」→ 綁定信用卡並購買額度（Credits）。沒有額度時 API 會回錯誤。
4. **建議設上限**：「Settings」→「Limits」可設定每月花費上限，避免意外用超過。
5. 建立金鑰：「Settings」→「API Keys」→「Create Key」，名稱可填 `tw-property-sheet`。
6. 畫面上會出現一串 `sk-ant-` 開頭的金鑰，**只會顯示這一次**，立刻複製。

### 填寫

```
ANTHROPIC_API_KEY=sk-ant-（剛剛複製的整串）
PSHEET_AI_MODEL=claude-sonnet-5-5
```

`PSHEET_AI_MODEL` 可以不改。想更省錢可以換成較小的模型（模型名稱以 Anthropic 官方文件為準）。

### 費用與注意

- 按實際用量（token）計費。這個工具每次只送物件條件（地址、坪數、格局、周邊），不送謄本原文，所以用量很小。
- AI 被要求只根據你填的資料寫，不寫保證增值、投報率等字眼；**產生後請自己看過再用**。
- 金鑰外流（例如不小心貼到網路上）：立刻回 Console →「API Keys」把那把金鑰刪掉（Disable／Delete），再建一把新的。

## 二、內政部地政平台金鑰 — 官方土地面積核對

### 這個功能做什麼

按下「🏛️ 官方面積核對」，程式會向內政部「地政整合資訊服務共享協作平台」查詢該筆土地的**土地登記標示部**，取得**官方登記面積**，並和你表單上的土地坪數比對（差超過 3% 會提醒）。
只查「標示部」（面積、使用分區、公告現值等），**不含所有權人等個人資料**。

### 申請步驟

> 平台的畫面、申請資格與審核流程可能調整，**原則上以平台網站公告為準**。以下是一般流程：

1. 打開 [地政整合資訊服務共享協作平台](https://cop.land.moi.gov.tw/)。
2. **註冊會員**：依身分選擇（公司行號、事務所或個人等），填寫基本資料並完成 Email 驗證。登入時會要求輸入圖形驗證碼。
3. **申請介接服務**：登入後找到服務申請，選擇「**土地標示部**」相關服務（服務名稱可能顯示為 LandDescription／依地號查詢土地標示部），填寫使用目的（例如：不動產經紀業務之物件面積核對），送出申請。
4. **等待審核**：核准後平台會通知。
5. **取得金鑰**：在平台的應用程式／API 金鑰管理頁面，取得 **Client ID** 與 **安全碼（Secret）**。
6. **付費**：依平台規定的方式繳費或儲值（按查詢筆數計費）。沒有餘額或服務未開通時，程式會顯示「地政平台驗證沒過」。

### 填寫

```
MOI_COP_CLIENT_ID=（平台給的 Client ID）
MOI_COP_SECRET=（平台給的安全碼）
MOI_DAILY_LIMIT=20
```

### 程式裡的省錢與防呆設計

| 設計 | 說明 |
|---|---|
| 要按「確認查詢」才查 | 第一次查某筆地號會先跳出「會收費」的確認按鈕 |
| 同一筆只收一次 | 查過的結果存在 `data/moi_cache.json`，之後再查同一筆直接用存檔、不再收費 |
| 每日上限 | `MOI_DAILY_LIMIT`（預設 20 筆）。到上限就停，隔天自動歸零 |
| 只在你的電腦上跑 | 金鑰只存在你電腦的 `.env`，瀏覽器頁面拿不到 |

### 常見錯誤

| 訊息 | 原因與解法 |
|---|---|
| 還沒設定地政平台金鑰 | `.env` 沒填或沒重新啟動 |
| 地政平台驗證沒過 | Client ID／安全碼打錯、服務尚未核准、帳戶沒有餘額 |
| 平台回覆錯誤 A0702 | 地段代碼或地號對不上，或平台暫時維護。先用「查地籍圖」確認地段地號正確 |
| 今天已達每日上限 | 隔天再查，或調高 `MOI_DAILY_LIMIT` |

## ⚠️ 很重要：有填金鑰時，不要把這個網頁直接公開到網路上

這個工具預設只開在你自己的電腦（`127.0.0.1`），是安全的。
如果你把它架到雲端主機、或用 cloudflared 之類的通道開給外面連，**任何拿到網址的人都能按按鈕，費用算在你的金鑰上**。要給同事用的話，請：

- 只在公司內網使用，或在前面加上登入保護（例如 Cloudflare Access、反向代理的帳號密碼）；
- 或者乾脆不要填金鑰，只用免費功能。
